# Langnostic

Translate flat string/FormatJS JSON catalogs and Markdown/MDX with your own AI
provider. See the [documentation](https://langnostic.com/docs) for supported
behavior, upcoming-release availability, and licensing.

## Development

```
pnpm dev
```

Before pushing, verify tests, lints, all pass:

```
pnpm verify
```

## Build

```
pnpm build
```
