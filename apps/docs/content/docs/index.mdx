Langnostic is a CLI for translating localization files and documentation before
you build or deploy your application. Configure source files, target locales,
and format plugins, then run `langnostic translate`.

Translations stay in your repository. You choose the AI provider and review the
generated changes using your existing development workflow.

## Supported content

The separately installed official plugins support:

- **FormatJS JSON:** Flat message-ID maps containing strings or FormatJS
  descriptors with `defaultMessage` and `description`.
- **Markdown/MDX:** Document blocks and translatable frontmatter fields, with a
  registry beside each source file for incremental translation.

The CLI works independently of your application framework. Your i18n runtime must
be able to consume the generated file schema. Nested JSON catalogs, XML, YAML,
TOML, and other localization formats need a suitable custom plugin; they are not
automatically supported because they are text files.

See [Using plugins](/docs/plugins) for formats, options, and authoring guidance.

## Use cases

- Fill missing translations in application message catalogs.
- Translate Markdown/MDX documentation and revisit changed source blocks.
- Run translation as a reviewable step in a development or release workflow.

Change detection depends on the plugin. FormatJS fills missing message IDs and
removes obsolete IDs; it does not detect source text edits under an existing ID.
MDX tracks source block and frontmatter hashes. Read the
[change-detection details](/docs/features#change-detection) before choosing a
workflow.

## How it fits into your application

An i18n library such as React Intl or i18next loads localized content and displays
it in your application. Langnostic translates files for that workflow; it does
not provide runtime localization APIs, extract strings from application source,
or translate a page after it loads.

You still need an extraction or authoring process that produces supported source
files, a compatible i18n runtime, and a review step for translations and syntax.
