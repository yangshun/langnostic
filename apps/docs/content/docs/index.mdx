Get Langnostic up and running in your project in just a few minutes.

## Prerequisites

- Node.js 18 or higher
- A project with JSON locale files or MDX files

## Installation

Install Langnostic in your project:

```bash
npm install langnostic
# or
pnpm add langnostic
# or
yarn add langnostic
```

## Initialize configuration

Create a configuration file with sensible defaults:

```bash
npx langnostic init
```

This creates a `langnostic.config.ts` file in your project root:

```typescript title="langnostic.config.ts"
import { openai } from '@ai-sdk/openai';
import JsonPlugin from '@langnostic/plugin-json';
import type { ConfigType } from 'langnostic';

export default {
  ai: {
    model: openai('gpt-4'),
  },
  groups: [
    {
      name: 'app-strings',
      paths: [
        {
          source: './src/locales/en-US.json',
          target: './src/locales/{locale}.json',
        },
      ],
      plugin: JsonPlugin(),
    },
  ],
  localeConfig: {
    source: 'en-US',
    target: ['zh-CN', 'es-ES', 'fr-FR'],
  },
} satisfies ConfigType;
```

## Set up your AI provider

Add your AI provider API key to your environment:

```bash title=".env"
# For OpenAI
OPENAI_API_KEY="your-api-key-here"

# For Google AI
GOOGLE_GENERATIVE_AI_API_KEY="your-api-key-here"

# For Anthropic
ANTHROPIC_API_KEY="your-api-key-here"
```

<Callout type="info">
  Get your API key from:
  - [OpenAI Platform](https://platform.openai.com/api-keys)
  - [Google AI Studio](https://aistudio.google.com/app/apikey)
  - [Anthropic Console](https://console.anthropic.com/)
</Callout>

## Configure for your project

Update the configuration to match your project structure:

```typescript title="langnostic.config.ts"
export default {
  ai: {
    model: openai('gpt-4'), // or google('gemini-1.5-pro'), anthropic('claude-3-5-sonnet-20241022')
  },
  localeConfig: {
    source: 'en-US',      // Your source language
    target: ['zh-CN'],     // Languages to translate to
  },
  groups: [
    {
      name: 'app',
      plugin: JsonPlugin(),
      paths: [
        {
          source: './src/locales/en-US.json',     // Your source file
          target: './src/locales/{locale}.json',  // {locale} will be replaced
        },
      ],
    },
  ],
} satisfies ConfigType;
```

## Run your first translation

Translate all new or modified content:

```bash
npx langnostic translate
```

<Callout type="success">
  Langnostic will automatically detect what needs translation and update your target locale files!
</Callout>

### Preview changes first

Want to see what would be translated without making changes?

```bash
npx langnostic translate --dry-run
```

### Debug mode

See the prompts and responses from the AI:

```bash
npx langnostic translate --debug
```

## Example: JSON locale files

Create a source locale file:

```json title="src/locales/en-US.json"
{
  "welcome": {
    "defaultMessage": "Welcome to our app!",
    "description": "Main welcome message"
  },
  "greeting": {
    "defaultMessage": "Hello, {username}!",
    "description": "Personalized greeting"
  }
}
```

Run translation:

```bash
npx langnostic translate
```

Langnostic creates the translated file:

```json title="src/locales/zh-CN.json"
{
  "welcome": {
    "defaultMessage": "欢迎来到我们的应用！",
    "description": "Main welcome message"
  },
  "greeting": {
    "defaultMessage": "你好，{username}！",
    "description": "Personalized greeting"
  }
}
```

## Example: MDX files

For MDX files, use the MDX plugin:

```typescript title="langnostic.config.ts"
import MdxPlugin from '@langnostic/plugin-mdx';

export default {
  // ... ai and localeConfig
  groups: [
    {
      name: 'docs',
      plugin: MdxPlugin(),
      paths: [
        {
          source: './docs/en-US/**/*.mdx',
          target: './docs/{locale}/**/*.mdx',
        },
      ],
    },
  ],
} satisfies ConfigType;
```

Create your source MDX file:

```mdx title="docs/en-US/getting-started.mdx"
---
title: Getting Started
description: Learn how to get started
---

# Getting Started

Welcome to our documentation!

<Alert>
  This is an important note.
</Alert>
```

Run translation and get:

```mdx title="docs/zh-CN/getting-started.mdx"
---
title: 入门指南
description: 学习如何开始
---

# 入门指南

欢迎阅读我们的文档！

<Alert>
  这是一个重要的提示。
</Alert>
```
